# M7.94: SPU sem lift e fragmentos PIC

O runtime do PS3Recomp já tinha `spu_interp_run`, mas o caminho de branch sem
lift só o chamava quando `SPU_INTERP_UNLIFTED` estava definido. O launcher iOS
agora define essa variável antes de iniciar a VM. O despacho continua procurando
funções SPU AOT primeiro; só branches sem função registrada entram no
interpretador.

Branches SPU não resolvidos também gravam a instrução e os 64 bytes seguintes
do Local Store no arquivo `spu-pic-fragments.txt`, dentro da pasta de captura
da execução em `Documents`. O botão **EXPORTAR CAPTURAS SPU (MÓDULOS + PIC)**
compartilha esse arquivo junto dos módulos sem lift já capturados.

## Gerar e integrar lifts PIC nativos

O arquivo PIC tem uma linha por fragmento:

```text
<PC do Local Store em hex> <overlay decimal> <64 bytes em hex>
```

Com o ELF privado que corresponde à instalação e o checkout fixado do
PS3Recomp usado pelo port de PC, gere os fontes:

```sh
git clone https://github.com/RichardFontoura/ps3recomp.git /tmp/ps3recomp-gowa
git -C /tmp/ps3recomp-gowa checkout f6ab60baf37662bd712592b7ef9f66891972a5fc
python3 tools/m793_lift_spu_pic.py \
  --ps3recomp /tmp/ps3recomp-gowa \
  --elf /caminho/privado/GOWA.ELF \
  --out runtime/m793-spu-pic \
  /caminho/privado/spu-pic-fragments.txt
```

O script localiza as assinaturas de 64 bytes no ELF, agrupa endereços próximos,
usa `spu_lifter.py --pic` para emitir código C independente de endereço e grava
uma função de registro explícita. No build iOS, `m772_build_ios.py` compila cada
`pic_*/spu_recomp.c`; `m772_bridge.cpp` chama o registro antes de iniciar os
workers SPU. Em runtime, o dispatcher compara as instruções reais na LS antes
de selecionar um lift PIC. Uma assinatura que não corresponda aos bytes do
ELF não é associada.

O build M7.94 inicial contém o interpretador e a captura PIC, mas não contém
fragmentos recompilados: ainda não há captura exportada do iPhone. A primeira
execução depois desta build é necessária para produzir essa entrada. A
compilação e o link do IPA, sozinhos, não provam que o jogo desenhou um frame.
