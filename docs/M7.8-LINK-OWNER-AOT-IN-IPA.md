# M7.8 — first public Actions build with owner-derived, signed native ARM64 Ascension AOT

This step is **recompilation**, not PowerPC interpretation. The iPhoneOS
application links a pretranslated module containing 11 PS3 guest entrypoints
from the user's own NPUA80918 decrypted ELF. Nothing runs without the
original ELF imported by the app on the user's iPhone.

## Required repository secret

The repository owner manually created `ASCENSION_AOT_SOURCE_GZIP_B64` in
KintTany Settings > Secrets and variables > Actions (not Codespaces). This is
the exact gzip+Base64 text from the user's M7.8 package, not the original ELF.

`tools/stage_m78_aot.py` decodes the secret on the Actions macOS runner,
verifies the fixed SHA256 `5b8d37c8a1880a727ef7ca6e0b6ceaca245a6fc69e89b7125e4b744ba7be8bd3`,
checks 11 function symbols, and places the C source in RUNNER_TEMP, using
GITHUB_ENV only for the path. A missing or wrong secret **fails CI**; it
cannot silently ship another diagnostic IPA with AOT=0.

`tools/build_ios_probe_ipa.sh` compiles the source under iPhoneOS Clang,
links with `-DASCENSION_PRIVATE_AOT_LINKED`, checks all 11 symbol names in
the **final unsigned iOS executable**, and writes `m78-aot-status.txt`.

## Additional required PS3 services

To reproduce the verified native-host boot prefix, generic iOS runtime
handlers have been wired to:

- sys_initialize_tls, NID 0x744680A2 (preexisting).
- sys_lwmutex_create, NID 0x2F85C0EF (M7.7).
- sys_time_get_system_time, NID 0x8461E528 (new, monotonic microseconds).
- sys_memory_get_user_memory_size, LV2 syscall 0x160 (new, guest BE memory
  info, explicitly modeled PS3 user-memory budget).

Imports are looked up via the authenticated PRX table for the imported ELF;
unknown PRX NIDs and syscall IDs still fail closed. The PS3 memory value
is a compatibility model, **not** iPhone available RAM.

The AOT module uses real signed ARM64 code; the independent legacy M7.2
interpreter report is not used by its dispatcher. New logs report
`funções nativas=11` and identify the first missing guest PC.

## Release and user verification

GitHub Actions artifacts in a **public** repository are potentially
downloadable by third parties; compiled game-derived machine code in the
IPA should not be considered secret despite the secret-source staging.
The user explicitly authorized operating on this public branch. No original
GOWA.ELF, RAP, game assets, or plaintext owner-derived source is committed.

The user's next iPhone test: install unsigned IPA after their signature,
import exact original NPUA80918 GOWA.ELF, copy PPU report, and confirm
`Funções registradas=11`, guest `r13`, runtime return code, and first
unresolved native PC. The host test earlier reached `0x00539998`;
iPhone behaviour remains to be measured. No RSX frames/gameplay claim.
