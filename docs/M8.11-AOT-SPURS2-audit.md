## Evidência de fonte: LFQueue não equivale a falta de trabalho
M8.10 counted every _cellSpursLFQueuePushBody entry as a push BEFORE native EDGE Zlib host fast path (PS3_EDGE_ZLIB_HLE=1). Successful EDGE operations intentionally return CELL_OK without reserving an LFQueue element. Hence 626 vs 0 cannot demonstrate failed queue transport. Added independent native EDGE attempts/completed/errors/bytes/event flags in the app's report.

## Diferença entre gowa-fixes e runtime iOS
gowa-pc (BCUS98232 update 1.12) uses RichardFontoura/ps3recomp branch gowa-fixes, whose persistent SPURS PM coordinator dispatches enabled registered policy modules without requiring a nonzero static per-lane priority. Our upstream pin 39a3629 + patches rejected WIDs16–31 if that priority byte was zero. M8.11 corrects this only for upper CellSpurs2 WIDs when SPURS_READY_LEVEL is on, preserving PM present/state/enabled/physical contention checks. Exposes guest-state masks from the **actual** runtime to verify eligibility and dispatch.

## No emulação
M8.10 explicitly set SPU_INTERP_UNLIFTED=1 and SPU_REJOIN_CALL=1. Both are now unset before guest boot, so no SPU fallback interpretation is requested; native AOT/PIC are the execution path. The interpreter's object code can remain linked as an unused library dependency, but is not an authorized runtime fallback. This can expose missing AOT coverage and stop progression earlier: it must be solved through offline static lift of exact NPUA SPU bytes, not by resuming an interpreter.

## Scope and limitations
These corrections do NOT claim first real frame: only the user's device can confirm that. User-supplied NPUA ELF is a different version than European BCES01741 or US retail BCUS98232 1.12 PC ports; never carry across guest addresses or translated code without exact bytes. The existing static jobmods (31), runtime PIC (2 entries), GCM FIFO and NPUA PSARC mounting are not declared complete merely because their binaries link. Next diagnostic decisively separates EDGE-only calls, workload eligibility, SPU native misses and graphical progress.
