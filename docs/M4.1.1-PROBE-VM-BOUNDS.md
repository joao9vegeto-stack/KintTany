# M4.1.1 — True bounded guest VM state in iOS probe

First M4.1 linker run #38684714752 failed only because the
PS3Recomp rsx_draw_engine.c expects vm_base and ppu_vm_size.
Those globals usually come from the per-title PPU boot loader, which
this DIAGNOSTIC intentionally does not link.

The host now provides an actual 16MiB calloc-backed test region.
The pointer and bounds are real, with safe zero-initialized bytes,
and the upstream draw engine refuses addresses outside ppu_vm_size.
No commercial PS3 content or license is loaded, faked or uploaded.
The buffer is released on failure and app shutdown.

This is strictly test infrastructure for Metal init/present and NOT
the guest memory subsystem used by God of War Ascension. The actual
game will need the full virtual memory mapping and native PPU core.
The prior M4.0 iOS Metal symbols and UIView integration remain intact.
