## Native-only architectural switch
- Compile `runtime/ppu_bridge.c` for iphoneos with `-DASCENSION_NATIVE_ONLY=1`. Its `ar_ppc_fallback_attach` refuses attachment and dispatcher excludes PPC instruction decode/evaluation: a missing native AOT/registered HLE immediately returns `AR_UNRESOLVED=-3` with exact guest PC.
- Compile `ios/ARLivePPUBridge.c` using same define, remove the legacy fallback attachment from production. `tools/build_ios_probe_ipa.sh` removes `ppu_m720_fallback.o` from the link and blocks the IPA if symbol `_ar_ppc_fallback_step` is found in final Mach-O. Host historical tests may still exercise interpreter in an entirely separate synthetic binary.
- The synthetic CI requires one true C AOT dispatch, rejection of interpreter attachment, missing-PC error with correct PC and zero PPC fallback steps.
- GOWA2 nine offline modules and 6251 entry symbols are unchanged and SHA-gated. **The archive of translated functions is not proof that all guest code is translated.**
