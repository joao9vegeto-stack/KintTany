# AscensionRecomp M6.7.2 — r12 and callee descriptor origin
Physical M6.7.1 NPUA80918: 39 real PPU instructions, -1007 on
bctrl PC=0x669C30 CTR=0x39800000. lwz r0,0(r12) PC=0x669C24
read 0x39800000 from EA=0x669C0C, followed by lwz r2,4(r12)
and mtctr r0. 0x39800000 also encodes li r12,0 (PPC),
suggesting but not proving code was read as descriptor data.

New optional evidence tracks r12's last writer PC/opcode, value,
EA if loaded, and two lwz words through base r12 with region and
original ELF segment p_flags. Regions 0 unmapped, 1 stack,
2 executable file-backed, 3 non-executable file-backed,
4 BSS data, 5 BSS with executable flag. No arbitrary executable
ranges, no opcodes ignored, -1007 remains fail-closed.
Both pre-existing PPU48 C APIs are preserved and all M4/M5
graphical probes remain unchanged. Host fixtures are synthetic only:
code treated as descriptor is rejected and a valid data
descriptor can jump to an already executable mapped target.
