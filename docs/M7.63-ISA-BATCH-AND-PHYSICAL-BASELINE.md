## What this commit adds

- Deterministic discovery of OPD + file-backed direct BL targets across the full canonical ELF.
- Preserve the pre-existing 805-function M7.62 IR; exclude its PCs. Automatically discover and conservatively lift 1582 *additional* whole straight-line functions, 8313 PPC words, into immutable semantic IR.
- Semantics: integer immediate arithmetic including XER.CA for ADDIC/ADDC, ADDIC. CR0;
  8/16/32/64-bit big-endian guest loads/stores, aligned indexed updates, GPR logic, LR/CTR,
  signed half-word and algebraic word load, low-word integer multiply.
- The actual 14-PPC `0x002C53BC` stop now has natively generated C with original ELF 56-byte SHA
  `511fb65b662c91435c7e95c25b0baac075236829d1629d34ed158af466398541`.
- New Apple compiler stage builds 17 C units + one authenticated installer, linking into final iOS Mach-O.
  Installer validates the complete original GOWA.ELF SHA and every original PPC guest word against guest RAM before registration.
  PC without AOT remains explicit AR_UNRESOLVED; no JIT, interpretation, placeholder or game-asset import.
- A native C host semantic regression tests the actual 14-PPC guest block: both XER.CA paths, LR,
  register preservation, 4 PPC big-endian stores, and fail-closed memory errors.
- CI verifies every native object and FINAL IPA symbols, separately from real iPhone execution.

## Offline and CI pipeline

Offline owner:
```
python3 tools/m763_expand.py --elf GOWA.ELF --baseline m762-full-inventory.json --output-dir m763-private
```
The baseline JSON is generated by the previous M7.62 full-ELF inventory, NOT hand-selected PCs.

CI (without original ELF) restores SHA-checked `runtime/m763_semantic_snapshot.gz.b64`
and runs `tools/m763_expand.py --snapshot m763-semantic-snapshot.json --output-dir runtime`.
All 1582 native symbols and the installer must exist in Apple ARM64 object files and the linked Mach-O.

## Acceptance and honesty

805 + 1582 = 2387 functions translated by these two conservative *new* batches;
this is NOT a whole-game percentage, and MANY functions in other historical AOT batches overlap.
Registered count on hardware will be measured in a NEW physical report; never sum counts blindly.
Real cellFsOpen/Read with positive bytes, full HLE/NID boot imports, SPU, RSX/Metal first game frame and gameplay remain unproven.
User requires future handoffs, IPA if build succeeds, exact Actions run, Git commit, comparison, and a continuity bundle.
