# AscensionRecomp M2.8 — Import stub to PS3 HLE NID dispatch

The PS3 PPU CFG smoke bridge now supports a game-agnostic guest import
stub -> NID table plus explicit NID -> host handler callbacks.
**Missing registered handler returns AR_MISSING_HLE (-8)** and records the
exact missing NID; there is no silent faked CELL_OK. A successfully registered
handler may read/write guest big-endian memory and has caller TOC restored
after its invocation. Duplicate entries are rejected.

Host tests translate a synthetic PPC function that calls a synthetic PS3
import stub. It first halts with the missing NID, then registers a real
test handler and confirms guest memory contents and preserved TOC/LR.
The GitHub workflow independently runs these tests using the full pinned
PS3Recomp PPU context header and cross-compiles the host bridge to Mach-O
iOS ARM64; no commercial game data is uploaded.

**Private evidence:** after staging real GOWA.ELF and translating two private
functions 0x10410 and 0x10534, execution reached PS3 import trampoline
0x669C0C, which belongs to sysPrxForUser NID 0x744680A2 in the ELF's import
manifest. No assumptions about this function's semantics or fabricated return
values have been made.

**Limitations:** This is a strictly single-threaded smoke bridge; it does not
automatically implement the 130 Ascension NIDs lacking upstream registrations,
nor prove the 220 registered handlers are correct. No real PS3 firmware
service, SPU/RSX, gameplay, or iOS IPA exists yet. Commercial code/RAP stay
private and outside CI.
