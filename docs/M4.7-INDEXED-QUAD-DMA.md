# M4.7: PS3 indexed-mesh u16/u32 DMA diagnostic

User's M4.6 video proves the native RSX vertex DMA triangle (magenta)
on iPhone: readback center 0xFFF64DD1, clear 0xFF18283D. Previous M4.5
inline green triangle and NV4097 color clears remain functional.
These are synthetic graphics tests, **not God of War rendering or FPS**.

This version adds a triple-tap path: write FOUR PS3 BE IEEE754
float4 vertices into a bounded guest-memory VBO; write SIX BE indices
0,1,2,0,2,3 into an independent bounded guest index buffer. Configure
NV4097_SET_VERTEX_DATA_ARRAY_OFFSET in main memory and real
NV4097_SET_INDEX_ARRAY_ADDRESS/DMA plus NV4097_DRAW_INDEX_ARRAY.
Two indexed triangles render a gold quad. Each next triple tap
alternates index format 16/32bit. GPU center readback is checked;
returns -31 missing engine, -32 bounds, -33 unchanged clear,
-34 wrong color. Do not report success on mismatch.

Prior tests fully retained: single tap RSX clear, long press inline
triangle, double tap DMA magenta triangle. Triple tap is the only
new path. The title's FP/VP shaders, texture sampling and real PPU
execution are still separate major work. No user game files in CI,
only isolated authorized branch, one commit/one Actions.
