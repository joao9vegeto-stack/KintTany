# M3.9 — Native iphoneos ARM64 RSX Metal backend (offscreen)

The M3.8.2 workflow #38683983691 SUCCEEDED with the larger pinned
PS3Recomp CPU/SPU/LV2 runtime library for iPhoneOS ARM64.

M3.9 enables the existing pinned upstream RSX Metal backend in the
iPhoneOS SDK build. The temporary CI overlay:
- Enables Objective-C and ARC for rsx_metal_backend.m.
- Guards its remaining unguarded NSWindow* declaration with
  !TARGET_OS_IPHONE, leaving Mac AppKit behavior unchanged.
- Uses the already-present iOS offscreen Metal texture branch in
  rsx_metal_backend_init (no NSWindow).
- Compiles library and requires rsx_metal_backend_init/shutdown to
  appear in exported archive symbols, failing the workflow otherwise.

This is native GPU BACKEND COMPILATION ONLY: there is no UIKit
CAMetalLayer drawable presenter, no iOS pad/audio adapters yet,
no actual Ascension executable on public runners, no guest texture
correctness validation, and NO game IPA or FPS measurement.

No source changes to upstream or other KintTany branches.
