M5.6.1 passed on the physical iPhone LINEAR/SWIZZLED (7/7/7).
M5.5 and M5.4 remain functional as reported by user.

1. palette0 with blend OFF and RT clear
2. palette1 ONE+ONE ADD => YELLOW,CYAN,WHITE,YELLOW
3. palette2 RED-only write mask => GREEN,WHITE,WHITE,GREEN

Only the first phase clears colour; each phase checks all four
ordered GPU readbacks and native draw counts 4/4/blend2/mask1.

Device must verify both layouts and older M5.6/5.5/5.4.
