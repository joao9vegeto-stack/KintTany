# M7.97 startup and FIFO park changes

This release candidate applies two changes to the iOS launch path:

- Before starting the guest, the launcher attaches and shows the actual `CAMetalLayer` used by the PS3Recomp Metal backend. While the guest run is active, switching launcher tabs no longer hides that surface. This is a visibility/lifecycle correction; it submits no synthetic draw and does not count as a game frame.
- The GCM FIFO park grace is set to `2,000,000,000` ms, matching the PC runner's configured resynchronization interval. This avoids the earlier 2-second resync that could skip queued guest FIFO commands while SPU jobs were still writing them.

The M7.96 device report did not capture live PPU instruction state or RSX get/put/current method and lock owner. Therefore this build does not claim that the first-frame blocker is fully identified or that a game frame has been produced. The IPA is a build deliverable; success still requires device evidence with guest draws and guest flips greater than zero and the game's own image.
