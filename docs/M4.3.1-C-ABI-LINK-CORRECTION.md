# M4.3.1 — Fix Mach-O symbol linkage at iOS app boundary

The M4.3 pipeline #38690789159 successfully compiled all pinned
PS3Recomp/RSX Metal dependencies and failed only at the final
iOS app link with Undefined symbol _ar_probe_rsx_clear_flip.

Root cause verified from the log: clang++ treats a .c input as
C++ (deprecated behavior warning), mangling the new guest-probe
function symbol; ARProbeApp.m expects the exact C symbol.

M4.3.1 compiles ARRSXMethodProbe.c explicitly with
xcrun --sdk iphoneos clang -std=c11 to its own Mach-O ARM64 .o,
validates exported _ar_probe_rsx_clear_flip via xcrun nm, then
links the tested object into the UIKit diagnostic IPA.

No change to Metal render path, RSX command stream, PPU/SPU
semantics or other branches. GitHub workflow remains branch-only,
one commit per run. Screen validation still required on device.
