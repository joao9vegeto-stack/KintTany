# M3.8.2 — iOS Mach VM region API adaptation

Previous iOS full-runtime build #38683719338 compiled 122/154 sources
before stopping on ONE unsupported macOS-only API in
runtime/platform/win32_compat.c:
- iPhone SDK intentionally rejects <mach/mach_vm.h>.
- macOS mach_vm_region is not available in the iOS SDK.

M3.8.2 adapts the EXISTING REAL OS-region lookup to the public
vm_region_64 API available from <mach/mach.h> for iOS devices.
No fake data is produced. Guest-facing memory mapping checks and
protections still inspect the actual kernel mapping and preserve the
original macOS implementation.

The patch is applied ONLY in a temporary checkout of pinned upstream
on the branch-isolated GitHub CI runner. It never modifies other branches
or the upstream repo. The iOS full runtime is still CPU/SPU/LV2 only:
SDL2 input/audio, Mac AppKit windows, and RSX Metal presentation are
explicitly not included until genuine device adapters exist.

The full iPhoneOS arm64 archive must BUILD before it is called complete.
No games or licenses are submitted to public CI.
