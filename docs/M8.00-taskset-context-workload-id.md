# M8.00: restore the taskset workload id in SPU context

## What the M7.99 capture says

The 7.99 report records 4,741,903 guest AOT calls, successful guest file
reads, and WWS policy scheduling activity, but still records zero guest draws
and flips. Its `0x00669A14` is a compiled import stub for `sys_lwcond_wait`
(NID `0x2A6D9D51`), not an old instruction loop. The HLE ring shows the call
from `0x006533A4`; `0x003C4FA4` remains a historical loop backedge marker.
Neither field is a live PPU instruction PC.

## Reference mismatch and correction

The exact US reference runtime at `RichardFontoura/ps3recomp:gowa-fixes`
builds its SPU taskset context with the active workload id at local-store
offset `0x1DC`, read from `taskset_ea + CSTS_WID`. The pinned iOS context
builder wrote the SPURS pointer, virtual SPU number, and DMA tag, then left
`0x1DC` zero. The lifted task library uses this field for workload-scoped task
API fast paths. That omission can leave PPU condition waits without the task
completion or signal they expect.

M8.00 adds the same big-endian workload-id write to
`spurs_pm_build_context()`. The runtime source patcher fails closed if the
field cannot be inserted or is missing. The final Mach-O gate also requires
`spurs_pm_build_context` to be linked into the IPA, alongside the SPU
interpreter and native WWS/PIC entries.

Reference points: the US runtime writes the field in
[spurs_pm.c](https://github.com/RichardFontoura/ps3recomp/blob/gowa-fixes/libs/spurs/spurs_pm.c#L93).
The EU Ascension port's SPURS patch also reads `wklCurrentId` from local-store
`0x1DC` when selecting the active workload in
[ps3recomp-0011](https://github.com/arnaldolima1/gow-ascension-pc/blob/master/patches/ps3recomp-0011-spurs-temparea-ready-level.patch#L250).

## Device result still required

This fixes a concrete mismatch in the guest SPU task context and connects that
fix to the final executable. The M7.99 phone capture still has no guest RSX
draws or flips; this source change alone is not evidence of a rendered frame.
The result is established only when the iPhone report has guest draws and
presented flips above zero and the video shows the game's image.
