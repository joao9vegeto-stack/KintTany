# AscensionRecomp M5.1 — guest shader DRAW real (diagnostic)

M5.0.4 compilation passed on user's actual iPhone on 2026-10-15.
M5.1 adds a separate device-only proof. It builds a synthetic NV40 VP with
MOV o0 (ATTR0) / MOV o7 (ATTR8), a TEX r0 TC0 fragment program, sends both
through NV4097 registers / guest memory, and renders a 2-triangle indexed
fullscreen quad using the real draw engine and Metal encoder. The texture is
PS3 A8R8G8B8 in main guest VM, linear or Morton swizzled, same four colors
as M4.9. The backend's own texture cache uploads it, not a new host texture.

Device check: tap **M5.1 · DRAW RSX TEX0 real** twice. First linear,
then swizzled. Accept only with guest draw count >0, actually encoded Metal
draw using translated FP sampling TEX0 and a bound resource, and four
distinct expected ARGB values from the actual presented RSX target. FAIL
includes stage, counters and four raw pixels. Do not pass on shader compile
or synthetic compute sampling alone. Old diagnostics must still work after
the new button because guest FP/texture/ATTR8 states are cleaned up.

CI confirms pinned source, static guards, arm64 iPhoneOS build, symbol linkage,
IPA integrity, and existing upstream tests. **CI cannot prove iPhone GPU pixels.**
The result remains a diagnostic application, NOT a native God of War: Ascension
game executable, and makes no FPS claims. No game ELF, RAP, PSARC, or content
is committed or uploaded. Only AscensionRecomp is updated.
