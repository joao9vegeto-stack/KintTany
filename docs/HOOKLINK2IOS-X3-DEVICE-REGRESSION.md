Source build: 45214405727, nxnative ee3ce6a02bc7, shader chain b6112b954691.

The latter is the direct termination reason, not a diagnosed SIGSEGV or jetsam. Keep the upstream 2 GB reserve. Free at least 12–20 GiB of actual space before testing, preferably 20 GiB if keeping the archive. Back up saves; never remove romfs.img or saves to clear cache.

The shader is in upstream game profile shader_map.tsv (ApplicationPackage/AglShader.sharcb, compute index 54, threadgroup 16x16x1). It is present in the prewarm manifest. Its Apple compiler failure is not proven to be a translator defect or caused by the archive. The source-level recovery tries the original border-corrected variant if its border-off specialization suffers an XPC interruption; otherwise limits retry to 0.5/1/2/4/8 s per shader variant, leaving failure visible rather than faking compute outputs. No claim this resolves compilation until an iPhone run succeeds. A 12 GiB free-space admission gate disables new PSO capture and compaction for the session; existing PSOs still readable, no added destructive cache cleanup. Full pair prebuild defaults off, prewarm remains; stable 30/no interpolation selected as a diagnostic default, 60 still selectable. Saved choices override defaults; use Reset to tested defaults or manually choose a mode.

No NUP unpack, no guest code rewriter, no translated shader rebuild. Workflow reuses exact source IPA, validates original report, re-extracts rewritten ARM64 sections, relinks pinned X3 runtime with eight checked anchors and compares original sections and Metal image CRC/size.
