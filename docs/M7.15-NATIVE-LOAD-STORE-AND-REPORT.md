## Fix for crucial M7.14 batch reporting omission
The M7.14 UI only included the 32-instruction frontier within the legacy PPU48 ERROR path. Device PPU48 returned success=0, so the user's advanced diagnostic omitted the inventory. M7.15 appends the frontier on both success and error paths, and adds an enabled-on-verified-frontier "Copiar lote PPC (até 32 instruções)" button in the Jogo/PPU tab. The copied data contain PC/words only, not the ELF/license.

The existing owner-only offline batch planner remains available in tools/m714_owner_batch.py. It does not magically translate unknown blocks on iOS. To add larger groups of independently authenticated AOT entrypoints, the owner must generate a complete private AOT bundle and stage it through a new GitHub secret. No interpreter, JIT or synthetic code fallback was introduced.
