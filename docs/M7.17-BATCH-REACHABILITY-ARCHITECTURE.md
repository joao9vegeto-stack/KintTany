# AscensionRecomp M7.17 — architecture shift from 4/15-instruction patches to measurable reachability and private bulk candidate generation

## Reason for this version
M7.16 on user's iPhone reported 68 signed ARM64 AOT entrypoints, native AR_UNRESOLVED at 0x003C4E14, TLS/guest SYSUTIL mappings OK, and no real RSX game frames. Its 11-word path branches (BL) to 0x003C4CB0; the alternate 4-word path BL targets 0x0052E180, which is an already linked owner AOT address. Translating one missing 11-instruction block per IPA would not scale. M7.17 deliberately does NOT claim to have compiled the rest of Ascension; it changes the architecture needed to discover and translate at scale.

## Native ARM64 dispatcher instrumentation
- Replaces O(number_of_registered_entries) linear lookup with bounded open-addressed 16384-slot indexing for up to 8192 signed AOT functions, while preserving duplicate rejection, 32-bit guest PCs, error behavior and reset.
- ar_trace_snapshot returns **actually executed native AOT** dispatch count, distinct registered entries invoked during the current ar_run, executed HLE count, real unresolved guest PC, execution budget, and latest 64 native entrypoint PCs. It explicitly does not count interpreted M7.2 steps as native AOT.
- On iPhone, ARLivePPUBridge copies this telemetry BEFORE the virtual-memory teardown.
- UI adds a M7.17 section to the existing "Copiar lote PPC" and Advanced Diagnostics reports.

## Read-only multi-root guest ELF control-flow inventory
- ar_m717_walk takes local SHA-256-verified ELF and at most 16 explicit roots, up to 2048 executable instructions.
- Roots include the actual unresolved native PC, the owner ELF entry, and recent real AOT PCs. The machine-readable output counts possible edges, conditional branches, direct calls, unknown indirect branches, syscalls, bad targets, truncation and up to 64 PT_LOAD-executable direct call targets.
- For unknown indirect targets, NO fake dynamic destination is invented. For direct calls/conditionals, both syntactic paths may be traversed; those are *possible static edges*, never claimed to have executed. Scan is bounded and contains no PPC interpreter, JIT or generated machine code.
- No relative path constraints or commercial ELF bytes are stored in the app, build artifact, GitHub repo, telemetry or clipboard. Only PCs and structural diagnostics may be copied.

## PRIVATE offline owner pipeline for larger AOT batches
tools/m717_owner_reachability.py accepts the original owner-only GOWA.ELF, optional iPhone diagnostic report, optionally manual roots and explicit budgets. It traverses a broader potential PPC callgraph (default 20k executable instructions, max 100k), checks direct call targets for executable PT_LOAD, and feeds candidate function roots to the already existing strict m714_owner_batch.plan + ppu_cfg_lifter.lift. Unsupported ISA, missing terminators, dynamic indirect branches and invalid ranges are reported/rejected instead of treated as supported.

Example (run ONLY in a private machine with your legitimately obtained ELF):
  python3 tools/m717_owner_reachability.py \
    --elf /private/GOWA.ELF \
    --report /private/iphone_m717_report.txt \
    --out /private/m717-plan --max-nodes 20000 --max-functions 1024

Produces callgraph-audit.json, aot-candidates-audit.json, candidate-functions.json. The candidates are **not automatically installable** in place of the 64 owner AOT entries; a future PRIVATE assembly must merge and verify all old functions and the new ones into a COMPLETE secret/source bundle. The existing secret ASCENSION_AOT_SOURCE_GZIP_B64 remains intact. Owner needs access to the original full ELF in an authorized private build to make substantial new executable coverage; GitHub Actions currently only has the pre-generated 64-owner-entry source and these 4 authenticated native fragments.

## Graphics milestone and invariants
The app's M4/M5 Metal tests remain synthetic. Nothing yet proves an Ascension RSX command stream, menu, texture or gameplay. No run should be misrepresented as full-game boot. This version is a real infrastructure milestone, not a gameplay release.

Preserve all M0-M7.16 regressions, work only on AscensionRecomp, one commit/one workflow, never touch main. Public repo may hold toolchain and small observed PPC opcode snippets, but no full commercial game files, decrypted ELF, license or GitHub credentials. Owner can privatize repo whenever desired.
