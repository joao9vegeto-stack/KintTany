# M4.0 — UIKit CAMetalLayer host interface (pre-boot)

Compile a minimal UIView whose layerClass is CAMetalLayer and whose
bindToPS3MetalBackend method supplies its real drawable layer to the
pinned RSX Metal backend BEFORE renderer initialization, on main thread.

A transient CI patch changes the existing iOS Metal path from
forced-offscreen to conditional:
- If an external CAMetalLayer is bound: s_layer is that layer,
  Metal device and format are configured, and windowed/present path
  gets drawable textures via nextDrawable.
- Otherwise: existing iOS headless/offscreen path remains intact.
- Mac/desktop NSWindow logic and backend behavior are unchanged.

CI MUST cross-compile the full iOS CPU/SPU/LV2+RSX Metal archive,
verify the C symbol rsx_metal_backend_set_ios_layer, and compile a
native UIKit ARMetalView ObjC object referencing it.

No PS3 game code, SELF, RAP, data assets or private shader was uploaded.
No signed IPA or game boot, actual GPU present, texture correctness,
30fps/60fps measurement is yet established. This is HOST integration,
not validated gameplay. GameController/CoreAudio still missing.
