  - 282 CFG boundaries unproven
  - 99 overlarge OPD intervals

- `0x002C53B0` discovered through call from `0x002C1714`, translated as three PPC words `lis r3,1; ori r3,r3,0x20; blr`, **not hard-coded into a PACKED list**.
- Data/literal pools and executable-section unknowns not counted as validated code, and no whole-game percentage claimed.

The conservative M7.62 translation whitelist is `addi/addis/ori/oris/xori/xoris/blr`; this is a strict subset of the existing experimental lifter, not a claim that every possible supported instruction was translated. Unsupported and ambiguous spans are **rejected**, not stubbed/converted to NOP. Imports/HLE/NIDs are untouched in this iteration, so no new import claims.

## Pipeline and separation of concerns
`python3 tools/m762_pipeline.py --elf /path/to/GOWA.ELF --output-dir m762-offline` inventories the **entire** authenticated OPD/direct-call candidate set; exports `m762-full-inventory.json` per-PC statuses, `m762-snapshot.json` (verified normalized semantic IR, not ELF bytes), 7 generated C units and one SHA/guest-RAM validating registrar.

Because Actions has **no original ELF secret**, production CI regenerates the *same* C from immutable `runtime/m762_semantic_snapshot.gz.b64`, SHA256 of uncompressed normalized IR `07b74c4557b4951c3c113c998dc5895932e28b33cf240fdc13f9315fe7d84eb3`. CI must not pretend to have reprocessed the original ELF. It recompiles semantic IR with Apple Clang into native ARM64, verifies every new symbol in the **final Mach-O**, and packages unsigned IPA. The source ELF stays with the owner. This snapshot is a **whole-inventory-derived IR archive**, not M7.61's 26 manually selected PPC word slices.

Install validation: full-size ELF SHA-256, executable guest PT_LOAD mapping, compare every selected word from original ELF with live guest RAM before registering any new native pointer. Registry enlarged 8192→16384 slots, preserving existing entries on duplicate PCs. No PPC interpreter, JIT, runtime decoder, fake filesystem read, fabricated RSX frame or synthetic GUI claim.
