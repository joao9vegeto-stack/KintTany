# AscensionRecomp M7.12 — authentic PPC ELF window at ARM64 AOT boundary

Base: M7.11.2 with 59 owner-derived, signed ARM64 guest entries. The device reported a missing entry at 0x002C1664.

M7.12 adds a read-only, bounds-checked inspection of the original NPUA80918 ELF64 big-endian executable PT_LOAD bytes at the *actual unresolved native dispatch PC*. It returns up to four authentic PPC instruction words and explicitly distinguishes missing ARM64 translation from an unknown import or non-executable address. Host tests cover a positive case, partial end-of-segment, misaligned PC, missing bytes, wrong execute flag and truncated ELF.

**This DOES NOT translate 0x002C1664 to ARM64.** A subsequent owner-generated AOT source containing that authentic block is necessary to advance native guest execution. No JIT, interpreter fallback or synthetic register effects are added.

ASCENSION_AOT_SOURCE_GZIP_B64 remains mandatory and SHA-256-pinned to M7.11's proven 59-entry native owner code. The script cannot read back a GitHub secret. No GOWA.ELF, SELF, RAP or commercial assets are checked in. Public Actions artifacts containing game-derived ARM64 are potentially accessible to others. Preserve M4/M5 probes and M6/M7 Advanced Diagnostics. One commit, one push workflow, iPhone verification required.
