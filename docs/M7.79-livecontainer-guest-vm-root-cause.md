# M7.79 LiveContainer guest-VM failure

The 7.78 device report and `IMG_5046_compressed.mov` establish the immediate
failure point. The app recognizes the selected `NPUA80918` folder and validates
the ELF entry at `0x00010410`, but the native run returns `host_rc=-7` before
loading any ELF `PT_LOAD` segment. VFS startup, guest file reads, AOT dispatch,
and RSX work therefore have not begun. The report records 21 fixed Mach
reservation attempts ending in `KERN_INVALID_ADDRESS`, followed by an 8-GiB
`mmap` fallback ending in `ENOMEM`.

The previous allocator required a 4-GiB-aligned host address because upstream
PS3Recomp recovered guest addresses by truncating host pointers. LiveContainer
already occupies or fragments the fixed ranges tested by that allocator, and
the 8-GiB fallback requests more contiguous virtual space than this process can
reserve. Selecting the folder alone cannot mount the guest VFS: the runtime
starts that mount only after the guest VM exists.

M7.79 changes the boot path in two linked ways:

- Reserve one 4-GiB guest window at any kernel-selected address, using the
  iOS-supported Mach `vm_allocate` API first and a 4-GiB `mmap` fallback. Only the existing low, RSX, and stack
  regions are made readable and writable.
- Translate host pointers inside that window back to guest EAs by subtracting
  its base. Preserve pointer-shaped 32-bit guest EAs. Reject unrelated 64-bit
  host pointers instead of truncating them into plausible guest addresses.
- Patch and attest all 370 pointer-narrowing sites in the pinned PS3Recomp
  source. The patcher checks for remaining conversions and can complete safely
  if a prior patch attempt stopped partway through.
- Permit either Mach VM or `mmap` to satisfy the host reservation regression;
  the fallback is a supported path, including on Apple systems.
- Correct the build gate, which still required the earlier 104-site count and
  would have stopped this revision before the iOS archive compile.

The GoW2 recompilation and PS3Recomp use a 4-GiB-aligned host window for their
desktop assumptions. The GoW Ascension PC port's Windows launcher and RSX path
do not provide an iOS allocator fix. M7.79 keeps the guest's 32-bit PS3 address
space while removing the host alignment assumption required by LiveContainer.

This removes the failure measured in the 7.78 report; it does not establish
that the game reaches its menu. That can only be measured after installing and
running the new IPA. The next report must show a successful reservation and
runtime initialization before any guest VFS, HLE, AOT, or RSX progress can be
claimed.
