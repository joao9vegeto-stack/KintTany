# M4.9 — NV4097 texture register → RSX texture cache → Metal binding

## Actual iPhone M4.8 video, 35.835s
Both LINEAR and SWIZZLED PS3 A8R8G8B8 decoded and GPU-sampled
with exact ARGB FFFF0000, FF00FF00, FF0000FF, FFFFFF00. Existing
NV4097 clear, inline green triangle, DMA magenta triangle and
u16/u32 indexed gold quad all remained visibly correct.

## New hardware diagnostic
M4.8 used a SEPARATE direct Metal sampler. In M4.9, a five-tap
test configures REAL NV4097 texture unit 0 using SET_TEXTURE_OFFSET,
FORMAT, CONTROL0/1/3, ADDRESS, FILTER and IMAGE_RECT. Four-quadrant
PS3 A,R,G,B bytes are stored in bounded guest memory in either
linear (0xA5) or Morton-swizzled (0x85) layout.

A genuine rsx_draw_engine_method NV4097_DRAW_ARRAYS triggers:
- the engine's rsx_dsp_get_texture() register decoding;
- sink_bind_textures() and eng_texture_slot() cache lookup/miss;
- eng_texture_upload() through rsx_texture_layout/decode;
- backend eng_texture_create/upload;
- backend eng_bind_textures() numeric handle;
- backend eng_encode_draw() binds that SAME Metal texture to actual
  GPU drawing record via setFragmentTexture.

A disposable CI overlay only adds a diagnostic hook capturing texture0
from the actual draw record (r->tex[0]); a small COMPUTE sampler samples
that precise Metal texture and synchronously reads four ARGB pixels.
All four values MUST match; null handle, wrong dimensions, MSL error,
GPU error and mismatch fail closed with an explicit error code.

IMPORTANT: this does NOT prove that real God of War pixel shaders
sample a texture. The engine's fixed program used here paints a gold
triangle and ignores texture0; the GPU diagnostic compute kernel samples
the ACTUAL texture resource bound to that draw. Enabling the real
NV4097 FP/VP shader translation remains future work. This test isolates
RSX register->resource binding, channel formats and GPU texture upload.

M4.9 does not modify the working fixed MSL shader or touch other
branches. Earlier probes remain accessible: 1 tap clear, long press
green inline, 2 taps magenta DMA, 3 taps gold indexed, 4 taps direct
texture GPU, and NEW 5 taps native NV4097 texture bind with LINEAR/
SWIZZLED alternating. On-device confirmation still required.
