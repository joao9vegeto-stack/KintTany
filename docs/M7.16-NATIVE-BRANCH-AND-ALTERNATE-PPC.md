## Corrected semantics and coverage
New ELF-verified ARM64 entrypoint at 0x003C4DC4 compiles exactly 15 words:
1. rldicl r31,r31,0,32 (truncate to low32).
2. stw r6,12(r29).
3. stw r4,20(r29).
4. stw r3,0(r4).
5. lwz r5,24(r29).
6. addis r4,0,0x9c (r4=0x009C0000).
7. stw r3,0(r5).
8. lwz r3,24(r29).
9. stw r31,4(r29).
10. stw r31,8(r29).
11. subfc r30,r31,r3 (r30 = r3 - r31; XER.CA = !borrow).
12. lbz r3,0x1780(r4).
13. rldicl r30,r30,0,32.
14. cmpwi cr0,r3,0 (signed low32 compare, CR0 includes XER.SO).
15. beq 0x003C4E14, else fall through 0x003C4E00.

Each memory read/write uses the validated big-endian guest VM. Any fault stops native execution; no made-up pointer, command, branch target, or fallback guest interpreter is inserted. Both successor addresses are derived from and validated against exact original executable bytes. The branch only updates CR0 and preserves all other CR fields and LR/CTR.
