# M6.0: first four guest PPU instructions executed on private iPhone ELF

M5.9 imported ELF64 Cell LV2 with exact NPUA80918 SHA-256 and OPD
entry. M6.0 interprets exactly four instructions via a generic
PowerPC64 subset (addi, oris, ori, lwz). Reads are bounded to
verified PT_LOAD segments, instruction fetches require X permissions.
No title bytes, private RAP, user executable or game-derived C are in
the public branch/IPA. The on-device user's import drives real instructions
from entry PC=0x10410 and reads TOC from private OPD memory, returning
r2=0x83F2B0 and next PC=0x10420. Host CI tests only unrelated
synthetic ELF fixture and rejects unknown opcode and out-of-range loads.
The parser and emulator never write the game's memory, call HLE,
SPURS, RSX FIFO, I/O, or enter gameplay.

Physical test: import the same GOWA.ELF through M5.9. Expect
'M6.0 PPU REAL: 4/4', R2=0x83F2B0 and next PC=0x10420.
Check M5.8.1 and M5.7 still pass. Success is not a full game boot.
Next: modeled stack and bounded guest memory writes, then HLE and SPURS.
