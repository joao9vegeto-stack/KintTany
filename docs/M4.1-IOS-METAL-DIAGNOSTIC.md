# M4.1 — Buildable native iPhone RSX Metal diagnostic application

Purpose: verify iPhone UIKit/CAMetalLayer plus the pinned PS3Recomp
RSX Metal backend can be LINKED into a real executable and packaged
as an *unsigned diagnostic IPA*. The host UIView creates a real
CAMetalLayer, supplies it before backend initialization, then
invokes rsx_metal_backend_init(960, 540) and one present.
A simple status label exposes success/failure on the iPhone.

This is not a game and has no game-loading features. No commercial
executable, source, license, assets, shaders or user secrets are
committed or included in public CI. The unsigned IPA must be signed
by a separate sideload workflow/tool to install on stock iOS.

The CI step MUST actually link the executable against the full pinned
native arm64 PS3Recomp runtime+Metal archive. Unresolved symbols or
incorrect app packaging fail the workflow and must be corrected.

This gives a concrete hardware-side diagnostic, but it cannot prove
God of War Ascension gameplay, PPU/SPU correctness, GPU texturing,
FPS, controls or audio. Those remain engineering stages.
