# M4.8 — Real PS3 texture decode and iPhone GPU sample validation

On-device M4.7 (2026-10-15 12:32:38, 33.93s) shows:
- Indexed u16 and u32 both passed, two triangles share four vertices,
  center pixel 0xFFF2D42E vs BG 0xFF162B43.
- M4.5 green inline vertex triangle, M4.6 magenta guest DMA vertex
  triangle and NV4097 RGBA clear/flip still work; no visible regression.
- None of this implies 30 or 60 FPS or working God of War graphics.

M4.8 adds a separate four-tap texture-format and GPU sample test:
- Writes an 8x8 synthetic four-quadrant picture to bounded guest memory
  using PS3 **A,R,G,B** bytes, not host RGBA bytes.
- Alternates NV4097 RSX source layout: 0xA5 linear (LN bit set), or
  0x85 Morton-swizzled (LN off). Uses the actual pinned
  rsx_swizzle_offset, rsx_texture_layout_pitched, rsx_texture_decode.
- Checks expected RGBA8 channels in CPU-decoded buffer, proving no
  accidental channel reversal and validating both layout variants.
- Uploads the result into a real Metal RGBA8 2D texture.
- Uses a deliberately SMALL NATIVE MSL diagnostic fragment shader
  to SAMPLE that texture (not merely clear the screen). Renders four
  quadrants through actual Metal draw, synchronizes GPU, reads four
  OFFSCREEN pixels back and compares exact ARGB against expected four
  unique palette entries. Does not claim success if any sample mismatches.
- Presents that sampled texture to the actual UIKit CAMetalLayer on
  success. Every stage returns a distinct failure code.

The native sampler is NOT the game's RSX fragment shader. This stage
validates the genuine RSX texture DECODER and the host's Metal texture
upload/sampling. NV4097 texture-unit binding, texture caches, mips,
BC formats, guest shader translator and actual Ascension materials
still require later engineering. Its purpose is to isolate texture
layout/channel failures from unknown guest shader problems.

Controls preserved: one tap NV4097 clear, long press green INLINE
triangle, double tap magenta DMA triangle, triple tap gold u16/u32 indexed
quad. Four taps test LINEAR/SWIZZLED texture alternately.
