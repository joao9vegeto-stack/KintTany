# M6.2 private PPU 16-instruction device gate

NPUA80918 user-owned ELF is used ONLY at runtime on iPhone.
Strict, bounded PowerPC64 interpreter now probes 16 instructions:
first eight from M6.1 and eight more from the called function.
New stage exercises nested STDU frame (-160), MFLR r0 and six
more STD register saves to a sandbox 4KiB simulated guest stack.
Expected on physical device: PPU REAL 16/16; PC=0x10554;
TOC/r2=0x83F2B0; LR=0x10430; SP=0x07000EF0;
9 stack writes, mflr/r0=0x10430.
CI compiles and runs generic synthetic PPC64 test only, including
unknown-opcode and out-of-stack fail-closed cases. No proprietary
game code, images, RAP or title assets in branch/IPA/Actions.
Previous M5.1–M5.8 GPU probes and M6.0/M6.1 gates are preserved.
This is NOT a full boot; HLE, syscalls, SPURS/SPU and gameplay
have not been executed. Physical iPhone validation required.
