# M3.8: first CPU/SPU/LV2 device-targeted upstream runtime attempt

This stage tries to build upstream PS3Recomp `ps3recomp_runtime` as a static
iphoneos ARM64 archive. CI checks out the EXACT pinned MIT source
a2c20108af45174dbb7d3e2f87f6acaaef09c6b4. The overlay modifies
ONLY the checkout inside the ephemeral CI job; the upstream remote and
all other KintTany branches are left untouched.

Known desktop-only obstacles are excluded explicitly:
- cellPad and cellAudio currently require desktop SDL2; iOS adapters for
  GameController and CoreAudio/AVAudioEngine must be added and proven later.
- The existing NSWindow/NSApplication RSX Metal backend is currently
  desktop-only. UIKit/CAMetalLayer native drawable support is separate work.
- AppKit is not linked against iphoneos. iOS framework links are Foundation,
  UIKit, Metal, and QuartzCore. SPU/PPU core and LV2 services stay included.

The CI step is intentionally a **real build requirement**: any remaining
cross-compilation error fails the run instead of claiming an imaginary
iOS-compatible runtime. When fixed it yields a usable native CPU/SPU/LV2
library, but NOT a complete game, graphics renderer, IPA or FPS result.

All tests use synthetic data; user-supplied PS3 code/assets/license remain
private and do not enter public GitHub artifacts.
