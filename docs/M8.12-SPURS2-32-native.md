M8.12 source correction: ps3recomp-0020-spurs2-32-workloads.patch ALREADY widens spurs_policy.c to 32 WIDs in prior builds. The previous assumption that the deployed runtime rejected all WID>=16 was NOT proven and is retracted. The upstream unpatched source retains 16, but our compiled runtime differs. This release does not reapply the already existing widening. Instead it instruments native SPURS2 policy entry/return/LS PC and records exact SPU non-AOT targets (opcode, image, overlay, LR), while disabling the remaining SMC micro-interpreter if strict native mode is enabled. SPURS counters are re-labelled correctly: spurs[3] total scheduler dispatch; spurs[4] high WID scheduler dispatch; spurs[5] PM resolution successes; spurs[6] PM resolution misses. RPCS3 NPUA80918 gameplay oracle had FIOS mediathreads and many PSARC reads, whereas current app only has 252 read calls and 2 draws. gowa-pc BCUS98232-1.12 and gow2-recomp NPUA80491 are behavioral references only. Rendering cannot be confirmed from CI.

Build integration correction: the two new native policy/LS-gap entry points are exported by the SPURS/HLE runtime archive, not the separate GOWA static AOT archive. Therefore do not require them at tools/m772_build_ios.py AOT prebuild nm gate. Instead require the exact exported symbol in both the compiled PS3Recomp iOS runtime m39-metal-symbols.txt and the final application Mach-O m43-probe-linked-symbols.txt; if absent the final build must fail.
