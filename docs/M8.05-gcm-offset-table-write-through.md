# M8.05 — GCM guest offset-table write-through

## Sintoma observado

A captura do aparelho mostra a interface nativa ativa, contadores de AOT e leitura de arquivos, mas a área de jogo continua preta. O relatório anterior também mediu `guest draws=0` e `guest flips=0`; isso não é evidência de travamento em um único PC. O PC amostrado `0x00419D1C` pertence a uma espera curta no caminho de sincronização do GCM, e `0x0066640C` é uma métrica de entrada AOT, não uma amostra confiável da instrução atualmente executada.

## Diferença concreta encontrada

O port de Ascension para PC inclui `ps3recomp-0005-gcm-offset-table.patch`. O comentário e a mudança do patch documentam que o jogo retém os ponteiros guest retornados por `cellGcmGetOffsetTable`, enquanto mapeamentos posteriores alteravam apenas as tabelas host. Assim, o guest podia continuar lendo `0xFFFF` (`iooffset == -1`) para páginas que acabara de mapear.

No runtime pinado pelo KintTany, `cellGcmGetOffsetTable` publicava uma cópia inicial das tabelas; `populate_offset_table` e `clear_offset_table` atualizavam as tabelas host, mas não escreviam as alterações posteriores na cópia guest. A aplicação iOS não instalava o patch 0005, embora aplicasse outros patches do port (0001, 0003, 0019 e 0020).

## Alteração M8.05

- Aplicar o patch 0005 ao runtime PS3Recomp pinado, com detecção de aplicação parcial.
- Exigir no verificador do build os marcadores de publicação e write-through das tabelas.
- Versionar o build como 8.0.5 e incluir este documento e o patch de origem no artefato.
- Não forçar comandos de draw, flips, estados de SPU ou códigos de sucesso. A correção mantém a lógica de mapeamento guest.

## Validação e limite da evidência

O patch passa `git apply --check` contra o checkout pinado. O workflow M8.05 valida a aplicação do patch, recompila e liga o runtime ARM64 e verifica a integridade/identidade da IPA. Isso não prova por si só que o iPhone renderiza: aceitação funcional exige uma execução no aparelho com `guest draws > 0`, `guest flips presented > 0` e pixels do jogo visíveis. Nenhum resultado de renderização é declarado neste documento antes dessa medição.
