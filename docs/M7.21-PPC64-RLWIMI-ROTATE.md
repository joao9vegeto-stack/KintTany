# AscensionRecomp M7.21 — PPC64 rotate/insert, no new AOT secret

## Source of diagnosis
The real signed owner NPUA80918 M7.20 TXT on iPhone reports
1,418 original AOT-linked functions, 1,511 ARM64 dispatches, 100
unique AOT functions reached, 17 authentic PPC interpreted steps and
429 HLE calls. The first unsupported authentic executable opcode was
0x5384C04A at PC 0x003C511C, identified as **rlwimi**.

The bounded experimental fallback DID progress past old missing AOT
0x003C4FC4 before stopping. It remains far from proof of game RSX,
real graphics or menu. Data from historical M7.2 is not current proof.

## Verified Power ISA semantics
M-form PPC64 RLWIMI takes (32-bit word from RS rotated left SH) and
inserts masked bits into the OLD destination RA, preserving all bits
outside MASK32(MB,ME). On PPC64, wrapped MASK32 MB>ME extends the mask
into the high 32 bits and the input is repeated word DATA32. Incorrect
zeroing/replacing whole RA can silently corrupt game pointer state.

M7.21 adds op20 RLWIMI and op23 RLWNM, and repairs op21 RLWINM to
follow PPC64 wrapped-mask semantics. MD/MDS rotates now include
rldic, rldimi, rldcl, rldcr beyond preexisting rldicl and rldicr.
Register state updates and optional Rc/CR0 are preserved.

Host tests use a made-up ELF with synthetic PPC instructions, not the
owner's encrypted, decrypted or commercial game data, and check mask
insertion, high halves on wraps, CR0/XER.SO, register variable shifts,
the 64-bit rotation/mask variants, unknown-opcode failure, with both
-O0 and -O2 UBSan.

## Safety and goal
- The AOT count remains **1,418**; this is not a fourth secret or bulk.
- Existing AOT interpreter dispatch priority, SHA-256 ELF
  authentication, guest memory boundaries, 2,048 PPC fallback limit,
  signed static code and unified TXT export remain unchanged.
- Each successful or rejected PPC guest step is counted separately from
  native AOT. No JIT or arbitrary injected ELF execution.
- Host tests + CI verify compilation; actual iPhone result is UNKNOWN
  until a new M7.21 unified report is uploaded.
- Beyond AOT, the eventual finish lines are real guest startup, HLE/LV2,
  game SPU services, RSX FIFO/draws, then reliable frame timings.
- Do not infer percent-complete from 100/1,418 distinct AOT dispatches.
