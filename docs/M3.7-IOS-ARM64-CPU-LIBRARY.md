# M3.7: device-targeted iOS ARM64 PPU bridge archive

Builds with the Xcode iphoneos SDK, target arm64-apple-ios17.0, pinned
upstream PS3Recomp's actual ppu_context ABI. This is a reusable static
library built from our bounded guest dispatcher, big-endian guest memory,
ELF64 PPU image staging, TLS initialization, LV2 memory-info syscall and
per-thread PPU thread ID.

The GitHub workflow verifies Mach-O archive arch and exported guest
entry symbols, then publishes the static library, public headers and
SHA-256 as a CI artifact. No commercial PS3 executable or license
is committed or passed through CI.

This is NOT the complete PS3Recomp runtime, game code, SPU/SPURS,
DMA, RSX graphics/Metal, VFS, or an iOS app/IPA. We cannot infer
gameplay or FPS from static library compilation.
