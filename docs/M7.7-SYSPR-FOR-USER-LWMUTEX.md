# AscensionRecomp M7.7 — sysPrxForUser native HLE for lightweight mutex create

## Evidence from the user's real NPUA80918 GOWA.ELF
- Original ELF SHA256: 4bf75c897b82d1beb25514cbadaff3d03e1b0c7bf849fa5d289be4f9183462b5.
- Original guest call stub: 0x00669A84, NID 0x2F85C0EF, sysPrxForUser.
- NID matches **sys_lwmutex_create**, not an arbitrary unknown HLE.
- The guest's attribute pointer 0x0068FD38 stores BE 0x00000002 (priority)
  and 0x00000010 (recursive), followed by ASCII name "_lc_mtx".
- Guest output pointer 0x00A38990 lies within its mapped BSS.
- The existing iOS M7.6.1 public IPA proved loader, PRX metadata and TLS,
  but has 0 commercial ARM64 functions linked.

## Added to the public generic runtime
- PRX resolver by exact library + NID, validated against executable ELF
  segment, rather than edition-specific address in source.
- HLE sys_lwmutex_create: validates two guest pointers and the attribute
  structure, writes the 24-byte BE guest mutex structure and creates a
  bounded bootstrap pseudo-id. On invalid attributes returns CELL_EINVAL.
- Per-process mutex table resets on native VM initialization. Unknown
  lock/unlock/wait remain explicitly **unimplemented**. The bootstrap
  service is *not* a full thread scheduler, SPU synchronization or guest
  lock-contention support.
- M7.0 native AOT path binds the matching import and handler. Its result
  bitmask adds 0x10 (matched lwmutex NID) and 0x20 (HLE bound), retaining
  previously established bits 0x1..0x8.
- PPU report M7.7 separately prints NID detection/HLE and signed game AOT
  count, so an imported HLE never masquerades as game execution.
- Synthetic CI: big-endian guest ABI, duplicate/invalid attributes,
  state reset, import-by-NID lookup and refusal of bad stub targets.

## Work still needed
- The distributed public IPA still reports game AOT=0 because the
  commercial-derived ARM64 source is not incorporated into the Actions
  build. The local M7.6 AOT work is independent and not tested on iPhone.
- Reaching lwmutex create through real signed AOT requires that source
  be linked before signing; then verify first call and next AOT fault.
- Future work: correct locks/unlocks and PPU thread interactions before
  running game threads. Never fake success for unsupported APIs.
- GTA5 iOS Port inspiration: explicit import bindings and fail-fast
  missing-function behavior. Its wasm2c and D3D11 shaders are not
  directly compatible with the PS3 PowerPC64 and RSX instructions.

This commit does not include game code, keys, decrypted ELF, or firmware.
