# M6.1 guest PPU bounded stack and branch

The user supplied NPUA80918 GOWA.ELF privately. This stage
adds four more guest instructions to M6.0's four, in a bounded
eight-instruction window. It emulates STDU and STD to a synthetic,
isolated 4096-byte guest stack (0x07000000..0x07001000), then
the real PPC relative branch/link. Expected on physical device:
8/8, r2=TOC 0x83F2B0, r1=0x07000F90, LR=0x10430, next PC 0x10534,
two virtual stack stores. Input ELF must pass M5.9 private SHA gate.
All title binaries and RAP stay OFF GitHub; CI uses synthetic data.
This does NOT execute PS3 LV2/SPURS, load assets or reach gameplay.
