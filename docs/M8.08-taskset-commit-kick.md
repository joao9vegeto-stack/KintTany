# M8.08 — WWS taskset scheduling on PUTLLC commit

Branch: AscensionRecomp. Guest: NPUA80918. No game content is added to this repository.

## Confirmed runtime discrepancy

M8.07 on iPhone had four registered tasksets, zero eligible task candidates,
zero valid task ELF admissions, six WWS workers without a task return,
and no confirmed rendered game pixels. The pinned PS3Recomp runtime awakens
parked WAIT_SIGNAL tasks when SPU PUTLLC/PUTLLUC commits a 128-byte guest line,
but only scans for SPU-created successor tasks when a previous task exits.
This can leave every worker waiting even though the guest has written new
ready/pending/enabled bits.

The RichardFontoura/ps3recomp gowa-fixes branch solves the missing notification
by calling spu_taskset_bits_committed from spu_taskset_line_committed.

## Changes

The actual M8.01 successor-task scanner is shared by task exit and atomic-line
commit. The scanner is invoked under the taskset scheduler lock, after the SPU
reservation lock has been released. Big-endian TaskInfo fields, guest bitsets,
valid ELF checks, running-bit guards, and dispatch statistics are preserved.
The existing WAIT_SIGNAL wakeup remains in place. Two counters distinguish
all delivered atomic commits from those hitting tracked tasksets.

Both PS3Recomp checkout copies are patched. The CI host test compiles the
production scanner and commit callback with synthetic guest taskset memory,
checking correct ELF address, single dispatch, no duplicate dispatch and
scheduler metrics. The linked iOS Mach-O must expose the new code path.

The sharing button now saves the same bounded live snapshot visible in the
report modal and presents the activity sheet from the topmost modal. File-write
errors are shown in the active UI.

## Acceptance

A passing GitHub Actions run verifies source, host regression, ARM64 symbol
linkage and IPA packaging. It does NOT demonstrate a rendered Ascension frame.
On-device evidence requires actual guest task candidates, accepted and
completed SPU work, useful PIC native execution, RSX draws and drawable-backed
guest flips, and visible game pixels. No task completion, draw or flip is
fabricated.
