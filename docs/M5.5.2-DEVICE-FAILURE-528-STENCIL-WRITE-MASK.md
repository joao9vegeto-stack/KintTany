# AscensionRecomp M5.5.2 — iPhone failure -528, root cause and fix

User physical iPhone screenshots on 2026-10-15 show M5.5.1 0.5.7
LINEAR and SWIZZLED: `FALHA -528 · fase 3`, guest/Metal 3/3,
stencil readout 0, pixels match palette0. M5.4 3/3/3 depth OK
in both layouts; M5.3 2/2 render-to-texture also OK.

## Concrete failure

In M5.5.1, NV4097_SET_STENCIL_FUNC_MASK at 0x0338 was set to
0xFF. This controls the **stencil read/compare mask**, NOT the write mask.
Pinned upstream:
- rsx_draw_engine.c eng_state_get reads `rs->s_write_mask` from raw
  NV4097 method 0x032C.
- rsx_metal_backend.m eng_pipeline_create sets
  `fsd.writeMask = rs->s_write_mask & 0xff`.
- rsx_dispatch_init seeds no value for 0x032C, so it is initially zero.

M5.5.1's first pass with stencil ALWAYS+ZPASS REPLACE therefore
drew colour but never wrote the ref1 stencil bits. Pass 2 EQUAL ref2
failed (as expected), and pass 3 EQUAL ref1 ALSO failed, producing
the observed -528. This is a source-supported root-cause analysis,
pending confirmation by device.

Fix: explicitly issue RSX NV4097 0x032C with 0xFF in stencil
modes 3/4/5 before rasterization, so the first REPLACE can write
all stencil bits. The pinned rsx_commands.h lacks the symbolic
constant, so M5.5.2 defines local M55_NV4097_SET_STENCIL_MASK 0x032C.
The real Metal guest stencil-draw counter now additionally requires
s_write_mask=0xFF and is fetched BEFORE pixel mismatch returns;
the old on-screen 0 was not conclusive because the code only
updated that value on success/error-return from the engine.

Host regression compiles pinned rsx_dispatch.c and checks that
register 0x032C starts at 0 and correctly receives 0xFF separately
from 0x0338; Python checks the guest command ordering, Metal
pipeline write-mask predicate, pixel-error telemetry, and no
regression of M5.4 depth or older guest TEX0 probes.

**Device proof required**: M5.5 twice (LINEAR then SWIZZLED),
expect 3/3/3 and correct pixels in all 3 phases, followed by M5.4
and M5.3 checks. This is a SYNTHETIC GPU test, NOT native
Ascension gameplay; no title files used or uploaded.
