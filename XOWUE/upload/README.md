# Local game input

Copy the legally obtained `default.xex` to `upload/default.xex` when using the
sample `generated/config/XOWUE.toml` directly. The `run_xowue_codegen.sh`
script can instead read an authorized XEX from any local path through the
`XOWUE_XEX` environment variable.

Do not add the XEX, title updates, DLC, or game assets to Git.
